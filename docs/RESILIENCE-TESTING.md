# Resilience Testing — NexaTech (M20)

## Principle

Document expected failure modes and **dry-run** operator procedures. Unattended agents **must not** kill pods, partition networks, or corrupt production data.

Dry-run helper: `scripts/resilience-dry-run.ps1|.sh` (prints planned checks only).
